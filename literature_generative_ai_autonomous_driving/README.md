# 生成式 AI × 自动驾驶极端场景论文资料

整理日期：2026-08-12；共收集 56 篇候选论文，其中 46 篇已下载为有效 PDF，10 篇保留官方论文入口。

本目录围绕本项目的第一版闭环：条件输入 → 结构化场景参数/JSON → 规则或物理校验 → CARLA 执行 → TTC/碰撞等风险评估。论文按相关性分为三档：

- **Tier A：核心方法**：优先精读，直接支持危险场景生成、可控生成、扩散模型、LLM 或闭环对抗测试。
- **Tier B：表示与测试基础**：支持 Scenic、OpenSCENARIO、CARLA、交通流生成和测试框架落地。
- **Tier C：扩展方向与综述**：世界模型、语言模型评估、数据集和方向性综述。

完整索引见 [`论文索引.csv`](论文索引.csv)，机器可读记录见 [`papers.json`](papers.json)，检索记录见 [`检索记录.md`](检索记录.md)。

## 推荐阅读顺序

1. `2202.02215`、`2304.10850`：建立场景生成方法与评测术语。
2. `TrafficGen`、`RealGen`、`DiffScene`、`ChatScene`：比较轨迹/场景参数生成、扩散模型与知识增强。
3. `Scenic`、`ScenarioNet`、`ISS-Scenario`：把模型输出映射为 CARLA/OpenSCENARIO 可执行表示。
4. `LLM-attacker`、`Seeking to Collide`、`LD-Scene`、`RiskFlow`：设计“生成—筛选—闭环测试”的第二阶段原型。

## 使用边界

- 预印本不等同于同行评审正式版本；同一工作如有 DOI，优先在论文中引用正式版本。
- 本项目当前 CARLA 批次结果主要用于接口和风险指标验证，不能直接宣称已具备生成模型训练规模；还需扩充结构化场景参数数据。
