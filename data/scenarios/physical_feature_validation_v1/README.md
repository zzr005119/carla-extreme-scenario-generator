# 物理增强候选 CARLA 配对验证 V1

## 实验设计

- 比较对象：原始 `15` 维风险代理候选与加入 `12` 个物理交互派生特征后的 `27` 维代理候选。
- 配对结构：`3` 个生成器 × `3` 个选择通道，共 `9` 对、`18` 个独立场景。
- 重复测量：每个场景使用 `3` 个 Traffic Manager 种子，共 `54` 次 CARLA 0.9.16 运行。
- 传感器档位：`RGB + Collision`；路线、传感器、版本和服务健康均执行严格验收。

## 验证结果

- `54/54` 次运行完成并严格验收，`18/18` 个独立场景数据完整。
- 三次实测风险档位完全一致：`18/18`；场景内风险分标准差均值 `0.399`。
- 物理增强侧实测风险均值 `73.568`，原始 15 维侧为 `65.531`，配对平均差 `+8.037`，中位数 `+4.907`。
- 物理增强侧在 `5/9` 对中风险更高，原始侧在 `4/9` 对中更高，尚不能证明普遍优势。
- 物理增强侧高风险及以上 `8/9`、碰撞场景 `6/9`；原始侧分别为 `7/9`、`4/9`。
- 物理增强侧外部 MAE `12.797`，原始侧 `15.503`；本轮支持将物理增强作为优先实验评分分支，但不支持移除原始 15 维基线。

## 结论边界

- 三个交通种子属于重复测量，独立样本量仍为 `18`，配对样本量为 `9`。
- 候选由风险代理主动筛选，不代表 LHS、GMM 或 CVAE 的原始总体分布。
- `target_risk_level` 是生成条件，危险性结论以 CARLA 实测 `observed_risk` 为准。
- 下一步将本轮 `18` 个独立场景并入风险反馈数据集，复训 V5 并检查物理增强收益是否保持。
