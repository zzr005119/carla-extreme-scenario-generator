# 风险反馈与代理 V2 阶段结论

## 数据与运行

- 风险反馈数据集由 V1 的 36 个独立场景与外部验证新增的 27 个独立场景合并，共 63 个独立场景。
- 三个生成器各 21 个场景；碰撞场景由 3 个增加到 18 个。
- Traffic Manager 种子仍作为同一场景的重复测量，不计为独立样本。
- 服务器已完成一次正式代理训练、50 次重复分层三折 OOF、自然比例 Top-16 诊断、同口径 Top-9 诊断和独立碰撞倾向诊断。
- 服务器输出目录使用了 `20260816` 时间戳；按项目当前日期 2026-08-15 判断，这是服务器时钟超前产生的目录名，不作为实验完成日期依据。

## 连续风险代理

- V1 随机森林：MAE `5.686`，RMSE `10.124`，Spearman `0.898`。
- V2 随机森林：MAE `11.536`，RMSE `14.343`，Spearman `0.740`。
- 同口径 Top-9 两两 Jaccard：V1 `0.708`，V2 `0.339`。
- 碰撞场景 MAE：V1 `30.145`，V2 `18.521`；碰撞风险的系统性低估有所缓解。
- V2 非碰撞场景 MAE 为 `8.741`，说明新增高风险分布使连续风险回归任务明显变难。

## 碰撞倾向通道

- 样本：18 个碰撞正样本、45 个非碰撞负样本。
- 50 次重复三折 OOF 中，随机森林 Average Precision 为 `0.532 ± 0.084`，ROC-AUC 为 `0.768 ± 0.052`。
- 阈值 0.5 下，Precision 为 `0.470`，Recall 为 `0.689`，F1 为 `0.557`。
- 该结果支持保留独立碰撞反馈通道，但不足以声明碰撞概率模型已经可跨地图或跨控制策略使用。

## 决策

1. 不用 V2 单一连续风险分数直接替代 V1 排序器。
2. 后续候选评分拆为连续风险与碰撞倾向两个通道，分别保存预测均值、波动和入选频率。
3. 碰撞倾向只用于候选配额和主动补样，不直接解释为连续风险分数。
4. 在完成双通道离线排序稳定性诊断前，不启动下一轮大规模 CARLA 仿真。
