# CARLA 0.9.16 迁移回归 V1

## 目的

在不改动 CARLA 0.9.15 历史结果的前提下，使用已经通过严格验收的确定性路线控制场景，对 CARLA 0.9.16 执行单场景、三个 Traffic Manager 种子的完整迁移回归。

## 固定条件

- 源配置：`data/scenarios/route_controller_smoke_v1/config.json`
- 源配置 SHA-256：`46FF0B24456085D945B635B8A4E5D21CE1F737CC3ACB21D92AF20F378F43AC23`
- CARLA 目录：`F:\Carla\carla-0.9.16`
- Conda 环境：`Carla666-0916`
- 服务端口：`2000`
- Traffic Manager 端口：`8000`
- 独立输出：`F:\Carla\output-0.9.16\migration_v1`

迁移配置仅修改场景名称和输出目录，不修改天气、参与者、事件时序、传感器、风险指标、路线或控制器参数。

## 验收条件

- 客户端与服务端版本均为 `0.9.16` 且一致。
- 场景状态为 `completed`。
- RGB 写盘状态为 `completed`，至少保存 `100` 帧。
- CARLA 服务健康状态为 `healthy`。
- 路线控制模式为 `waypoint_follower`。
- 主车、前车和双车同时在途率均为 `1.0`。
- 主车与前车最大路线偏差均不超过 `3.0 m`。
- 清理后不存在由本次测试启动的 CARLA 0.9.16 进程。

## 与 CARLA 0.9.15 对照

对照数据来自 `cvae_repeatability_v4` 中同一场景、同一组交通种子的结果；两版配置除场景名称和输出目录外保持一致。

| 指标 | CARLA 0.9.15 | CARLA 0.9.16 | 变化 |
|---|---:|---:|---:|
| 平均风险分 | `27.760` | `27.491` | `-0.269`（`-0.97%`） |
| 风险分样本标准差 | `0.063` | `0.587` | 约 `9.31` 倍 |
| 风险分极差 | `0.122` | `1.137` | 约 `9.32` 倍 |
| 平均最小 TTC | `1.686 s` | `1.705 s` | `+0.019 s` |
| 最小 TTC 极差 | `0.032 s` | `0.040 s` | 约 `1.25` 倍 |
| 平均最小净间距 | `4.352 m` | `4.413 m` | `+0.061 m` |
| 最小净间距极差 | `0.092 m` | `0.474 m` | 约 `5.15` 倍 |

0.9.16 的风险分和净间距波动相对 0.9.15 明显增大，但绝对风险分极差仍只有 `1.137`，三次风险档、路线状态、传感器状态和服务状态完全一致，未出现此前未锁定路线时的执行分支跳变。当前证据支持“存在可测的数值波动增大，但未发现影响工程验收的兼容性回退”；由于只有一个场景和三个种子，不作统计显著性结论。

## 迁移结论

- CARLA 0.9.16 迁移回归严格验收 `3/3`，版本升级门槛已满足。
- 从 2026-08-15 起，后续新增实验默认使用 CARLA 0.9.16 和 `Carla666-0916`；CARLA 0.9.15 保留为历史结果复现基线。
- 不把 0.9.15 与 0.9.16 的运行结果混入同一实验批次；跨版本比较必须保留版本字段并单独报告。
- 后续批次继续执行传感器、服务健康、路线和 CARLA 版本四类严格验收。
