# 风险指标拆解校准 V1 阶段结论

## V3 与 V4

- V3：`81` 个独立场景、`24` 个碰撞场景。
- V4：`99` 个独立场景、`29` 个碰撞场景。
- V4 相对 V3 的 MAE 从 `11.769` 降至 `11.617`，RMSE 从 `14.319` 降至 `14.149`。
- V4 的 Spearman 从 `0.743` 降至 `0.706`，Top-9 两两 Jaccard 从 `0.375` 降至 `0.296`。
- 碰撞场景 MAE 从 `18.376` 升至 `18.946`，碰撞平均低估仍约 `18.8` 分。

V4 增加了边界样本并略微改善总体数值误差，但没有改善高风险内部排序和碰撞低估，因此不能直接替代 V3 成为唯一 Top-K 排序器。

## 分数拆解

当前 `heuristic_v2` 中碰撞权重为 `0.25`，其余连续风险分量合计为 `0.75`。校准实验比较三种方案：

1. `single_total`：直接预测最终风险分数。
2. `decomposed`：分别预测连续风险分量与碰撞运行率，再按原权重合成。
3. `oracle_collision`：连续风险分量仍由模型预测，但使用真实碰撞运行率，只作为诊断上限。

主要结果：

- 总体 MAE：`11.588 / 11.567 / 3.298`。
- Spearman：`0.708 / 0.710 / 0.943`。
- Top-9 两两 Jaccard：`0.310 / 0.316 / 0.445`。
- 碰撞场景 MAE：`18.903 / 19.006 / 5.222`。
- 碰撞场景平均偏差：`-18.728 / -18.775 / -3.682`。

拆解模型只将总体 MAE 改善 `0.020`，50 次重复中仅 `27/50` 次 MAE 更低；Top-9 实测命中率平均下降 `0.020`，碰撞场景 MAE 反而增加 `0.104`。该变化不构成替换依据。

## 碰撞通道

- V4 碰撞正样本 `29` 个，非碰撞负样本 `70` 个。
- 随机森林碰撞分类器 AP 为 `0.508 ± 0.064`，ROC-AUC 为 `0.733 ± 0.038`。
- Recall 为 `0.605 ± 0.112`，F1 为 `0.516 ± 0.067`。
- 相比 V2 的 AP `0.532`、ROC-AUC `0.768`、Recall `0.689`，新增样本没有带来改善。

## 决策

1. 不修改 `heuristic_v2` 的碰撞权重。降低权重只会掩盖预测误差，并削弱碰撞在风险定义中的意义。
2. 不用拆解模型替换当前单一风险代理；V4 用于高风险粗筛和反馈数据积累，不宣称其能稳定完成 Top-K 精细排序。
3. 独立碰撞通道继续用于主动补样、候选配额和误差诊断，不解释为真实碰撞概率。
4. 下一轮不新增 CARLA 大批次，先从现有参数构造运行前可计算的物理交互特征，并做同口径离线 OOF 对照。

## 解释边界

99 个独立场景只支持工程校准诊断，不支持统计显著性结论。Traffic Manager 种子已经聚合为场景级重复测量，不能作为独立样本重复计数。
