## 四、采用的申请范围

拟登记软件定位为面向自动驾驶场景研究与仿真测试的本地应用软件，而非生产级多用户平台。主操作链为“设计参数并生成候选 → 校验并编译单场景配置 → 明确启动 CARLA 客户端 → 分析遥测 → 查看与导出证据”。已有场景库只读查询独立于新候选生成，不承诺在 Web 中自动入库。

LHS、GMM、CVAE、Diffusion 的参数生成入口均存在；后三者依赖匹配模型产物。Web 数量范围为 1-64，多条记录可批量校验，但现有直接编译和执行衔接仅面向单条有效记录。不能把批量校验写成批量 Web 实机执行。

当前库是 117 个独立场景和 351 条历史来源批次严格验收证据，不是本轮新增仿真。36 个条目有逐次证据，81 个条目只有聚合证据；场景级 CARLA 版本未记录，真实性均为 `not_assessed`。不能因当前运行基线为 0.9.16，反向补填这些历史版本。

`target_risk_level` 是设计条件；只有输入遥测来自真实 CARLA 运行时，`observed_risk` 才具有实测含义。`heuristic_v2` 是仿真遥测启发式评分，不是事故概率、车辆安全认证或真实道路泛化结论。

设计页本地三维预览是固定道路与车辆、行人示意，不是生成候选、真实城市模型或实测轨迹。传感器回放要求原始文件仍可读取，历史帧与遥测按帧序近似对齐，相对车距示意也不是地图轨迹。

Web 当前默认可启动本机 CARLA 客户端，但不会启动 CARLA 服务。项目实机任务仍遵守“服务器优先，连接或健康检查失败后回退本机”的执行规则；远端通过既有显式工具提交、回收并人工导入 Web，不承诺服务器 Job 自动调度和轮询。本轮不启动任何实机任务。

M08 最小演示读取既有生成记录和历史风险，默认 `carla_connected=false`，不产生新的实测风险。OpenSCENARIO 仅描述最小交换适配，不扩大为完整 ScenarioRunner、跨地图或批量兼容。
